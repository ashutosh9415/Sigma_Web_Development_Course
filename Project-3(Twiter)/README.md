# Twitter Clone Project

This is a Twitter clone project using Tailwind CSS v4.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Build CSS (one-time):
   ```bash
   npm run build-css
   ```

3. For development with auto-rebuild:
   ```bash
   npm run watch-css
   ```

## File Structure

- `src/input.css` - Input CSS file with Tailwind imports
- `src/output.css` - Compiled CSS file (generated)
- `src/index.html` - Main HTML file

## Development

Open `src/index.html` in your browser to see the result. The CSS will automatically rebuild when you run `npm run watch-css`.
